这是静态展示版：识别在你的浏览器里完成（本地 OCR，照片不上传、不需要 API Key）， 判定引擎是完整版的 JS 移植。批量核验、条码查询、手动补录与 PDF 报告等完整功能， 请下载程序包在本机运行（说明与局限）。

拍照核验

流程：上传照片 → 浏览器内本地 OCR（文字检测 → 版面分区）→ 你对照包装核对改正 → 开始判定。 不需要 API Key；还没有照片时，可以先点示例库体验判定引擎。

识别设置（视觉大模型）

识别在你的浏览器里完成（ONNX Runtime Web 加载 RapidOCR 的 ONNX 模型做文字检测与识别）， 照片不会上传到任何服务器，也不需要申请 API Key。首次使用需要下载模型文件，之后会走浏览器缓存。

第一步 · 标签照片
识别完成后会出现「第二步 · 核对识别结果」，那里才真正出判定结论。
第二步 · 核对识别结果（判定前请先核对）

识别结果仅供参考，请核对后再判定——OCR 同样会读错： 倾斜、反光、小字粘连都会让某几行读漏或读错，而判定引擎再准也救不回一份错的输入。 下面把识别到的配料表、营养成分表与宣称语都摊开成可编辑的字段， 请对照包装改正后再点「开始判定」。
